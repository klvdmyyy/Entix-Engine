# Building from Source

Entix Engine are cross-platform (or would be cross-platform laterly) and currently
supports following target platforms:

- Linux
- Windows

:::{caution}
Windows support are unstable because my main system is Linux-based. I just don't have
enough time to fully test it on Windows
:::

## Windows

First step to build Entix Engine on Windows is Visual Studio installation.

:::{important}
You also need to install **Address Sanitizer**, **Clang** and **LLVM tools** for **Debug** build
:::
